# Experiment launchers

Shell launchers that produced the results of the study, in the order they were run. Run them from the repository root, for example
`bash experiments/main_final.sh`, ideally inside a detached tmux session; every launcher writes to `logs/` and `runs/`, both ignored by git.
Aggregate results are in `results/`; `scripts/paper_tables.py` and `scripts/paper_figures.py` turn them into the tables and figures of the paper.

| Launcher | Purpose |
|---|---|
| `main_tune.sh`, `main_queue.sh` | Equal-budget random search per method and dataset (`TRIALS`, `FINAL_SEEDS`); `main_queue.sh` loops over several datasets |
| `main_gate.sh` | Sanity gate of the protocol: spectral views next to the random-drop views of the original node script |
| `main_round3.sh`, `main_round4.sh` | Tuning of the full method on the citation graphs and Amazon-Photos, then the heterophilous graphs with the dose-response runs |
| `main_sprint.sh`, `main_deep*.sh` | Deadline sprints: dose-response, reduced heterophilous study, scaling, attacks, TU replication |
| `main_full.sh`, `main_full_resume.sh`, `main_dose_rerun.sh` | The complete plan: attack graphs, tuning, dose-response, attacks, TU views, seeds, summaries |
| `main_round5_s1.sh`, `main_round5_s2.sh` | GraphSAGE control, robustness attribution, open-gate seeds, generator memory profile, tuned TU comparison, fresh-process scaling |
| `main_final.sh` | GraphMAE on the heterophilous graphs, PolyGCL, GraphSAGE and MLP controls on the homophilous graphs |

Helper scripts that these launchers call live in `scripts/` (`jobpool.py` memory-aware job pool, `tune_node.py` random search, `run_best.py` retraining with fresh seeds,
`ablate.py`, `dose_response.py`, `make_attacks.py`, `paired_encoder.py`, `summarize_tuning.py`). The job lists in `jobs/` are generated by `scripts/make_jobs*.py`.
